# atlas-compare · 跨书对比

把多个 `data.json` 放在一起，产出可比指标和并排视图。

## 前置

至少两本已拆解的书：

```bash
ls output/*/data.json
```

**schema 版本必须一致。** 版本不同先转换：

```bash
python scripts/migrate.py --from 1.0 --to 1.0 ...
```

## 可比指标

| 指标 | 计算方式 | 说明什么 |
|---|---|---|
| 人物数 | `entities` 中 `type=character` 的个数 | 世界规模 |
| 关系数 | `relations` 条数 | 关系复杂度 |
| 关系密度 | 关系数 / 人物数 | >3 说明人物高度交织，<1.5 说明结构松散 |
| 平均度数 | `2 × 关系数 / 人物数` | 单个角色平均连接数 |
| 势力数 | `group` 去重后的个数 | 阵营复杂度 |
| 情感线占比 | `type=romance` 边数 / 总边数 | 题材倾向 |
| 冲突线占比 | `type=conflict` 边数 / 总边数 | 戏剧强度 |
| 主线跨度 | `events[].ch` 的首尾差 / `chapters` | 叙事密度 |
| 平均章节张力 | `events[].tension` 均值 | 整体节奏 |
| 设定密度 | (`places` + `concepts`) / 万字 | 世界观厚度 |

**这些指标只在 schema 一致时可比。** 这就是为什么关系类型必须收敛到 8 类——否则"情感线占比"根本算不出来。

## 执行

```bash
python scripts/compare.py \
  --a output/红楼梦/data.json \
  --b output/西游记/data.json \
  --out output/_compare/
```

产出：

```
output/_compare/
  metrics.md          指标对照表
  compare.html        并排视图（两个图谱 + 指标条）
  diff.json           差异明细
```

## 输出格式

```markdown
## 红楼梦 vs 西游记

| 指标 | 红楼梦 | 西游记 | 差异 |
|---|---:|---:|---|
| 人物数 | 51 | 63 | +12 |
| 关系数 | 86 | 94 | +8 |
| 关系密度 | 1.69 | 1.49 | -0.20 |
| 势力数 | 8 | 6 | -2 |
| 情感线占比 | 11.6% | 1.1% | -10.5pp |
| 冲突线占比 | 9.3% | 22.3% | +13.0pp |
| 平均章节张力 | 0.69 | 0.61 | -0.08 |

**结论**：西游记冲突密度是红楼梦的 2.4 倍，情感线几乎为零；
红楼梦人物关系更交织（密度高 13%），势力更分散。
```

## 硬性约束

1. **不要跨 schema 版本硬比。** 字段含义变了，比出来的数字是错的。
2. **不要在样本量不足时下结论。** 只对比 2 本书时说"这个作者的风格是……"是过度归纳。
3. **指标要给绝对值和相对值。** 只看百分比会误导（西游记总关系多，分母不同）。

## 已知限制

- 关系类型靠模型判定，跨书可能有标注漂移（同一段关系在一本书标 `social`，另一本标 `alliance`）
- `group` 的划分标准各书不同，势力数只能同书系内比
- 目前只支持 2 本并排，3 本以上是表格不是图
