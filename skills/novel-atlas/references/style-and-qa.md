# 视觉与验收

## 风格

浅绛淡彩水墨，纸面为底。不是油画、不是羊皮纸奇幻、不是 Inkarnate/Wonderdraft 的默认西方地图。

- 纸面：`ui_paper_ornate`，底色 `#E8DCC5`。
- 墨线：`#3B332A`；朱印：`#A93828`；赭石：`#A66A45`；水色：`#6E8E96`；路线：`#8A7254`。
- 陆地：极淡暖色水洗，不画闭合粗边。
- 海/虚空：明显主体。海用代码渐变 + 椭圆水彩斑 + 横向波纹 + 模糊海岸；虚空更暗、更空。
- 山：远山淡、主峰略重，山体不要大到盖住节点；山脊优先 `terrain_ridge_01/02`。
- 建筑：小体量，贴节点，不抢题签。
- 题签：竖排为主，字号上限 `0.053`；朱印在题签正下方，自动定位。

## 构图

- 地图内容裁在纸面内框内，不压纸边、题签、罗盘、免责小印。
- 题签左上、罗盘右下（或左下）、免责左下；三者不互相压。
- 单层视图允许留白，但不自动放大到选区；全幅纸面是默认。
- 标签避让：先排 rank1，再 rank2；被 UI 或越界挤掉的标签直接剔除，不硬挤。
- 移动端题签最小 11px，印章最小 16px；不能为了塞字把整张图缩小。

## 标签层级

| 缩放 | 显示 |
|---|---|
| fit / 100% | rank1 + 部分 rank2 |
| 约 1.25× | rank2 候选明显增加 |
| 约 1.95× | rank2/3 进入，但画面裁切后只剩中心附近 |
| 复位 100% | 回到 fitKx/fitKy，不是 `k=1` |

验收时看 `window.__atlasMap.stats()`：`textTotal` 是候选数，`kept` 是实际留下的标签数，`overlapPairs` 应为 0。具体数字随数据集变化，不要把某一本书的 14/10 当成固定目标。

## 分辨率

至少三档：

| 视口 | 检查 |
|---|---|
| 1440×900 | 默认全图、题签、海面、标签 |
| 1920×1080 | 题签末字不被印章压、标签不贴边 |
| 390×844 | 题签可读、印章不糊、地图不溢出 |

再加：

- 每个 `layer` 的单层视图
- 1.25× / 1.95× / 100% 复位
- 桌面右键拖拽、移动端单指拖拽都能平移；百分比读数随缩放变化
- 控制台零 JS 报错

## 体积

- 21 件 PNG 原始约 11 MB，转 webp 后约 1.07 MB。
- 单文件页内联 23 张（21 + 纸底 + 海纹），原始约 1,075 KB，base64 后约 1.44 MB。
- 构建日志应显示“内联 23 张”。少一张说明纸底或海纹没打进，多一张说明混进了旧装饰。
- 页面过大时用 `--external` 把数据写成 `data.js`，不要把 21 件图删掉来省体积。

## 验收记录建议

每次改地图，保留：

```text
qa-<book>-1440.png
qa-<book>-1920.png
qa-<book>-layer-<id>.png
qa-<book>-zoom.png
qa-<book>-reset.png
qa-<book>-mobile.png
```

看截图时优先看：题签末字、印章位置、海面接缝、建筑是否压标记、层切换后建筑是否还在原地。
