# 地点地理层级 · L1–L4

`places[].parent` 只表达**地理包含**；`level` 表达**地理类型**，`branch` 表达它属于哪条一级分支。两者分开，避免把“州”硬塞进“城池”层，也避免为了凑层级给真实地名加后缀。

## 三条 L1 分支

| `branch` | L1 类型 | 典型实际名称 |
|---|---|---|
| `continent` | 大陆 / 大陆内的地域总览 | `天南`、`大晋`、`极西之地` |
| `ocean` | 海洋 / 海域 | `乱星海`、`五龙海`、`无边海` |
| `realm` | 界面 / 位面 / 悬空秘境 | `人界`、`灵界`、`仙界` |

**L1 名称必须是数据里的原名**，不能写“越国大陆”“乱星海海域”。分支类型由 `branch` 承担，不靠后缀。

## 层级定义

### 大陆分支

| level | 类型 | 说明 |
|---|---|---|
| 1 | 大陆 / 地域总览 | 一个或多个国家、州的上位容器；可以是真实地名，也可以是标了 `virtual` 的分支容器 |
| 2 | 区域 / 州 / 国 | 巨型板块、行政州、具体政权。国下可以再挂州；两者都是 L2，行政细分允许同级嵌套 |
| 3 | 城池 / 山脉 / 坊市 | 凡人城池、修真坊市、巨型山脉、关隘、战场等可落脚地点 |
| 4 | 宗门 / 家族 / 洞府 | 宗门驻地、家族宅院、个人洞府、殿阁、密室等附属于 L3 的具体据点 |

### 海洋分支

| level | 类型 | 说明 |
|---|---|---|
| 1 | 海洋 / 海域总览 | `乱星海` 这类大海域 |
| 2 | 内海 / 外海 | 人类活动内圈、妖兽外圈；天然屏障两侧 |
| 3 | 群岛 / 特殊海域 | 主岛、群岛、妖兽海渊、特殊环境海域 |
| 4 | 岛屿 / 海沟 / 秘境 | 宗门岛、荒岛、海底洞府、周期性秘境入口等 |

### 界面分支

| level | 类型 | 说明 |
|---|---|---|
| 1 | 界面 / 位面 | `人界`、`灵界` 等纵向位面 |
| 2 | 秘境 / 禁地 | 周期性秘境、上古遗迹、天然禁地、异空间 |
| 3 | 关卡 / 分区 / 特殊地貌 | 内殿、冰火道、环形山、石墙村落等秘境内部大区 |
| 4 | 殿阁 / 洞府 / 密室 | 具体取宝点、闭关地、石室、传送阵等 |

## 硬规则

1. **L1 不能空**：除 L1 外，每个地点都必须有 `parent`；沿 `parent` 上溯必须终止在一个 `level=1` 地点。
2. **不跨级**：子级 `level` 最多比父级大 1；允许同级嵌套（国下挂州、岛上挂城、宗门下再挂堂口）。
3. **不硬造后缀**：L1 用原名；不知道上级时，挂到最近的已知 L1，并保留 `attrs` 里的政治归属，不虚构“某某大陆”。
4. **分支容器**：确实没有真实上位地名时，允许加 `virtual: true` 的 L1/L2 容器，只用于挂载，不计作剧情地点。容器 `first_ch` 写 `0`，不要伪造首现章。
5. **地图层根**：如果地点为了地理层级被挂到 L1 下、但仍要当地图层根，标 `map_layer: true`；地图层计算会在这里停止上溯。
6. **归属和包含分开**：`parent` 只写地理包含；政治/势力归属继续放 `attrs` 或 `entities`，不要为了“归到越国”而改地理父级。

## 《凡人修仙传》当前样例

```text
大陆
└─ 天南 (L1)
   └─ 越国 (L2)
      └─ 镜州 (L2，州与国同级)
         └─ 青牛镇 (L3)
            └─ 春香酒楼 (L4)
      └─ 越京城 (L3)
         └─ 秦府 (L4)

海洋
└─ 乱星海 (L1)
   └─ 内海 (L2)
      └─ 魁星岛 (L3)
         └─ 魁星城 (L3，岛上城池与岛同级)
            └─ 天都街 (L4)
   └─ 外星海 (L2)
      └─ 奇渊岛 (L3)
         └─ 黑石城 (L3)
            └─ 明珠轩 (L4)

界面
└─ 人界 (L1)
   └─ 虚天殿 (L2，悬空秘境)
      └─ 虚天店内殿 (L3)
         └─ 寒骊台 (L4)
```

## 字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `level` | int 1–4 | 地理类型层级；不是 parent 深度，因此国下挂州仍为 L2 |
| `branch` | enum | `continent` / `ocean` / `realm`；子地点继承 L1 |
| `virtual` | bool | 可选；地理分支容器，不是剧情地点 |
| `map_layer` | bool | 可选；该地点仍是地图层根，计算层时停止上溯 |
| `geo_order` | int | 可选；同层 L1 的阅读顺序（大陆→海洋→界面），不参与层级判定 |

## 抽取时的判定顺序

1. 这条地点属于大陆、海洋还是界面？先定 `branch`。
2. 它最像 L1 总览、L2 区域/州/国、L3 城池/山脉/坊市，还是 L4 宗门/家族/洞府？定 `level`。
3. 找原文写明的上位地点；找不到就挂最近的已知 L1/L2，不要留 `parent: null`。
4. 如果只有“所属势力”没有地理上级，把势力写进 `attrs`，不要拿势力当 `parent`。
