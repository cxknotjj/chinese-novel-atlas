## 0. 发布前必做的三件事

**① 数字必须现算，不要凭记忆写。**
本文所有数字来自 `output/凡人修仙传/data.json`。重跑后先执行：

```bash
python -c "import json;d=json.load(open('output/凡人修仙传/data.json',encoding='utf-8'));from collections import Counter;print(len(d['entities']),len(d['relations']),len(d.get('places') or []));print(Counter(f['status'] for f in d['foreshadows']))"
```

**② 措辞红线：说「到第 500 章仍未回收」，不说「作者忘了」。**
《凡人修仙传》是完本作品，大量伏笔在 500 章之后才收。写成「作者忘了收」会被书粉当场反驳，且不成立。正确表述是「我读到 500 章，这 79 个坑还开着」——这是读者视角的事实，不是对作品的判断。

**③ 不要声称分析过全书。**
只分析了 2443 章中的前 500 章。所有文案必须带「前 500 章」这个限定。

## 2. 小红书 / 微博

**标题**
我把《凡人修仙传》前500章喂给AI，它揪出79个没填的坑

**正文**

追《凡人》的时候总有这种时刻：看到一个人名，心想"这人谁啊"，往前翻三章找不到，搜一下又被剧透一脸。

所以我干脆写了个工具，把整本书拆成结构化的档案。

我拿它跑了前 500 章（720 万字），出来这些东西：

· 384 个人物、459 条关系，谁和谁什么关系，点一下就高亮
· 119 个地点，从青牛镇到血色禁地，按 parent 层级排成树
· 215 条伏笔，其中 **79 条到第 500 章还没回收**

最离谱的一条：第 7 章韩立练口诀"只练出一丝凉气，与正阳劲的热流截然不同"——这个来历不明的凉气，到第 500 章都没解释，**沉默 493 章**。

还有第 20 章埋的抽髓丸（厉飞雨靠它强撑功力），427 章没再提过。

它判断"遗忘"的方式挺有意思：不是看埋了多久，而是看**最后一次被提及是第几章**。所以像小瓶这种贯穿全书的主线不会被误报，只有真断了的线索才会标红。

所有结论都能点回原文的具体段落，不是 AI 瞎编。

## 3. V2EX / 即刻 / 少数派

**标题**
做了个把网文拆成世界百科的 Agent Skill，开源

**正文**

写这个的起因很具体：读长篇网文时想查一个配角，只能往前翻，或者去搜——而搜索必然剧透。

所以我做了套 skill，把整本书编译成结构化档案，再按阅读进度截断发布。

**它做什么**

6 个 skill：分析、问答、对比、导出、地图、疑点复核。挂在 Claude Code / Codex 这类 Agent 下用自然语言调用。

跑完一本 720 万字的书（前 500 章）大概产出：
- 384 实体 / 459 关系 / 119 地点 / 215 伏笔
- 一份 `data.json`，投影成八个视图：人物图谱、百科、地点志、地图、势力版图、节奏曲线、境界轨迹、伏笔台账

**几个我认为有意思的设计**

1. **伏笔超期看「沉默时长」而不是「埋了多久」**
   第 7 章埋、第 196 章还在提的主线不该报警；第 20 章埋、第 73 章后再没提的才该。实测同一本书，只按埋设跨度判出 37 条超期，加上沉默时长后降到 23 条，且剩下的是真问题。

2. **境界体系必须全局定义**
   逐批抽取时每批只看 10 章，各批 `order` 独立编号，合并后必然错乱——实测出现过「筑基」被排成第一境、全部角色战力时间线为空。现在改成全文扫描 + `realms.json` 权威定义 + merge 注入。

3. **每条结论带 `chN:pM` 坐标**
   没有原文证据的推断不写入档案。疑点（比如已死角色再出场）标为「数据候选」，由作者复核，不直接判决。

**不做什么**
不做精确 GIS（示意地图不承担经纬度）、不做 SaaS 书库（默认本地，稿件不上传）。

## 4. 知乎

**问题（自问自答，或用现有问题）**

> 网文动辄几百万字，作者怎么管理人物、伏笔和设定不出错？

**回答结构**

1. **先说行业现状**：大部分作者用 Excel + 备忘录，人物一多就崩；有些用 Notion；极少用专业工具（如 Scrivener 的卡片）。
2. **拆解真正的难点**：不是「记不住」，是三件事——
   - 时间维度：第 120 章的设定，第 40 章不能出现
   - 空间维度：谁在哪、势力范围怎么变
   - 因果维度：埋的坑有没有填
3. **我的做法**（介绍项目，附数据）
4. **几个反直觉的结论**
   - 伏笔超期应该看「多久没提」而不是「埋了多久」
   - 境界体系必须全局定义，逐批抽取必然错乱
   - 地图对连载作者的价值低于「层级树 + 势力版图」
5. **局限**：AI 抽取有噪声，需要人工复核；不适用于短篇。
